## ⚡ Быстрый старт

```bash
# 1. Установка (автоматическое определение GPU)
./setup.sh   # Linux/macOS
setup.bat    # Windows

# 2. Запуск
./run.sh     # Linux/macOS
run.bat      # Windows
```

**Пример полного цикла работы:**

1. **Разметка** → Откройте папку с фото → Создайте классы → Разметьте объекты → Экспортируйте датасет
2. **Обучение** → Создайте проект → Выберите датасет → Выберите пресет → Запустите обучение
3. **Анализ** → Загрузите обученную модель (`best.pt`) → Откройте фото → Анализируйте

## 🔧 Установка

### Автоматическая (рекомендуется)

Скрипт определит ваше оборудование и установит правильную версию PyTorch:

**Linux / macOS:**
```bash
chmod +x setup.sh
./setup.sh
```

**Windows:**
```cmd
setup.bat
```

> **Что делает скрипт:**
> 1. Определяет тип GPU (NVIDIA/AMD/Intel/Apple Silicon)
> 2. Создаёт виртуальное окружение
> 3. Устанавливает PyTorch для вашего оборудования
> 4. Устанавливает все зависимости
> 5. Проверяет работоспособность

### Ручная установка

<details>
<summary>Показать инструкции</summary>

#### 1. Системные зависимости (только Linux)
```bash
# Ubuntu/Debian
sudo apt install python3-pyqt5 libxcb-xinerama0 libxkbcommon-x11-0

# Arch/Manjaro
sudo pacman -S python-pyqt5

# Fedora
sudo dnf install python3-qt5
```

#### 2. Виртуальное окружение
```bash
# Linux (с доступом к системному PyQt5):
python3 -m venv .venv --system-site-packages

# Windows/macOS:
python3 -m venv .venv

# Активация:
source .venv/bin/activate  # Linux/Mac
.venv\Scripts\activate     # Windows
```

#### 3. PyTorch

Выберите команду для вашего оборудования (https://pytorch.org/get-started/locally/):

| Оборудование | Команда |
|--------------|---------|
| **NVIDIA GPU** | `pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121` |
| **AMD GPU (Linux)** | `pip install torch torchvision --index-url https://download.pytorch.org/whl/rocm6.0` |
| **Intel GPU** | `pip install torch torchvision intel-extension-for-pytorch` |
| **Apple Silicon** | `pip install torch torchvision` |
| **CPU** | `pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu` |

#### 4. Зависимости
```bash
pip install -r requirements.txt
```

</details>

## 📖 Использование

### 1. 📝 Разметка изображений

**Подготовка:**
1. Откройте папку с изображениями (📁 Открыть папку)
2. Создайте набор классов (+) и добавьте классы

**Разметка:**
| Инструмент | Использование |
|------------|---------------|
| **Box** | Клик + перетаскивание для прямоугольника |
| **Polygon** | Клики для точек, двойной клик или Enter — замкнуть |
| **Выбор** | Клик по объекту для выделения, перетаскивание для перемещения |

**Экспорт:**
1. Укажите % для валидации (рекомендуется 10-20%)
2. Нажмите "Экспортировать датасет"
3. Выберите папку — получите готовый датасет YOLO с `data.yaml`

### 2. 🚀 Обучение модели

**Создание проекта:**
1. Нажмите "Создать" и введите название
2. Выберите файл `data.yaml` вашего датасета
3. Выберите тип задачи (Детекция/Сегментация)

**Настройка:**
| Параметр | Рекомендация |
|----------|--------------|
| **Модель** | Nano для теста, Medium для баланса, Large для качества |
| **Пресет** | Выберите по размеру датасета |
| **Аугментация** | Средняя для большинства задач |

**Запуск:**
1. Нажмите "Начать обучение"
2. Следите за метриками (Train Loss должен падать ▼)
3. Модель сохранится в `runs/train/weights/best.pt`

### 3. 🔍 Анализ результатов

**Загрузка:**
1. Загрузите веса модели (файл `best.pt`)
2. Откройте изображение для анализа

**Анализ:**
1. Нажмите "Анализировать"
2. Настройте порог уверенности (меньше = больше детекций)
3. Кликните на класс в результатах для фильтрации

**Коррекция:**
1. Включите "Режим правки"
2. Исправьте ошибки модели (добавьте/удалите/измените объекты)
3. Нажмите "Сохранить для дообучения" — данные сохранятся в `feedback_data/`

## 📊 Параметры обучения

| Параметр | Описание | Рекомендация |
|----------|----------|--------------|
| **Эпохи** | Количество полных проходов по датасету | 100-300 |
| **Batch Size** | Количество изображений за один проход | -1 (авто) или 8-32 |
| **Размер фото** | Разрешение для обучения (должно делиться на 32) | 640 (стандарт), 1280 (мелкие объекты) |
| **Learning Rate** | Скорость обучения (lr0) | 0.01 (стандарт), 0.001 (малый датасет) |

> **Совет:** Если обучение падает с ошибкой "CUDA out of memory", уменьшите Batch Size или размер изображения.

## 🎨 Аугментация данных

Аугментация — автоматическое изменение изображений для улучшения обобщающей способности модели.

| Уровень | Когда использовать | Что включает |
|---------|-------------------|--------------|
| 🚫 **Без** | Идеально чистые данные | Ничего |
| 🌱 **Лёгкая** | Хорошие данные, небольшие вариации | HSV ±5%, поворот ±5°, flip, mosaic 50% |
| 🌿 **Средняя** | Большинство задач | HSV ±7%, поворот ±10°, mosaic + mixup 10% |
| 🌳 **Сильная** | Шумные/разнородные данные, мало фото | HSV ±9%, поворот ±20°, все аугментации |

**Параметры аугментации (для опытных):**

| Параметр | Описание |
|----------|----------|
| `hsv_h/s/v` | Изменение оттенка, насыщенности, яркости |
| `mosaic` | Комбинация 4 изображений в одно (0.0-1.0) |
| `mixup` | Наложение двух изображений с прозрачностью |
| `copy_paste` | Копирование объектов между изображениями (для сегментации) |
| `degrees` | Случайный поворот (±градусы) |
| `translate` | Случайное смещение |
| `scale` | Случайное масштабирование |

## ❓ Устранение проблем

<details>
<summary><b>Ошибка: "Could not find the Qt platform plugin xcb"</b></summary>

**Решение 1:** Используйте системный PyQt5
```bash
rm -rf .venv
python3 -m venv .venv --system-site-packages
source .venv/bin/activate
pip install ultralytics pyyaml pillow
```

**Решение 2:** Установите системные библиотеки
```bash
sudo apt install python3-pyqt5 libxcb-xinerama0 libxkbcommon-x11-0
```
</details>

<details>
<summary><b>Ошибка: "CUDA out of memory"</b></summary>

- Уменьшите **Batch Size** (попробуйте 8, 4, или 2)
- Уменьшите **Размер изображения** (попробуйте 416 или 320)
- Используйте модель **Nano** вместо Large/XLarge
</details>

<details>
<summary><b>Долгое обучение на CPU</b></summary>

- Используйте пресет "💻 Для CPU"
- Уменьшите количество эпох (30-50)
- Используйте модель Nano
</details>

<details>
<summary><b>Модель не распознаёт объекты</b></summary>

- Проверьте разметку — объекты должны быть полностью внутри рамок
- Увеличьте количество эпох
- Попробуйте уровень аугментации "Сильная"
- Добавьте больше примеров в датасет (минимум 50 на класс)
</details>

<details>
<summary><b>Переобучение (Train Loss падает, Val Loss растёт)</b></summary>

- Увеличьте аугментацию до "Сильной"
- Добавьте больше данных
- Уменьшите количество эпох
- Используйте Early Stopping (patience)
</details>
