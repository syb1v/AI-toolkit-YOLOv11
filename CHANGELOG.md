# Changelog

Все важные изменения в проекте документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
проект придерживается [Семантического версионирования](https://semver.org/lang/ru/).

---

## [2.0.0] - 2026-01-15

### Добавлено
- **Вкладка разметки**: Bounding Box и Polygon инструменты
- **Вкладка обучения**: 8 пресетов, 4 уровня аугментации, мониторинг в реальном времени
- **Вкладка анализа**: Инференс, настройка порога уверенности, режим коррекции
- **Иерархия классов**: Группировка классов (родитель → подклассы)
- **Автосохранение**: Сохранение прогресса каждые 30 секунд
- **Поддержка оборудования**: NVIDIA CUDA, AMD ROCm, Intel oneAPI, Apple Metal, CPU
- **Сохранение для дообучения**: Экспорт исправлений в feedback_data/

### Изменено
- Полностью переработан интерфейс на PyQt5
- Улучшены всплывающие подсказки с информацией из документации Ultralytics
- Очищен код от лишних комментариев

### Исправлено
- Стабильность работы на Linux с системным PyQt5
- Корректное определение GPU на разных платформах

## Как вести Changelog

### Категории изменений:
- **Добавлено** (Added) — новые функции
- **Изменено** (Changed) — изменения в существующем функционале
- **Устарело** (Deprecated) — функции, которые будут удалены
- **Удалено** (Removed) — удалённые функции
- **Исправлено** (Fixed) — исправления багов
- **Безопасность** (Security) — исправления уязвимостей

### Правила:
1. Новая версия всегда вверху файла
2. Дата в формате YYYY-MM-DD
3. Группировка по категориям
4. Краткое описание (1-2 строки на изменение)
5. При необходимости — ссылки на issues/PR

### Пример новой версии:
```markdown
## [2.1.0] - 2026-02-01

### Добавлено
- Поддержка YOLOv12 моделей
- Экспорт в формат COCO

### Исправлено
- Ошибка при загрузке больших изображений (#42)
```

### Версионирование (SemVer):
- **MAJOR** (2.x.x) — несовместимые изменения API
- **MINOR** (x.1.x) — новый функционал, обратно совместимый
- **PATCH** (x.x.1) — багфиксы, обратно совместимые
